## 1 本轮做什么、不做什么

做：把 WS/T 363.3—2023 的一个数据元、WS/T 364.3—2023 的一个值域表与 13 个代码，连同来源包、成员位置、页码和原记录，读进 HDIP 的独立只读资料域，并做出“数据元 → 值域 → 代码 → 出处 → 原记录”的连续阅读路径。

不做：院内采用、业务字段映射、规则执行、发布与消费、导入审批页面、Drive 自动同步、上传页面、F2 的分页筛选与整族接入。不读取院内部门、人员、患者数据。

## 3 F1 第一条阅读路径（约 4–6 天）

### 3.1 导入命令

`uv run python scripts/import_standards.py <包 ZIP 路径> --family ws363-364 [--select DE02.01.031.00,CV02.01.101]`

- 登记包（大小、本地 SHA、预期 SHA 与比对结论、成员清单）→ 按资料族读取器读选定成员 → 写 `source_document`（标准号、分册、原文年份、结构化修订、读取器版本）→ 写条目与引用。
- 读取器按“结构化文档修订 + 条目类型 + 源记录键”去重：重复导入不增条目；扩大 `--select` 范围只补新记录并更新覆盖清单。
- 解析失败：整次导入在一个事务里回滚，报文件 / 记录位置，已有内容不变。
- 直接读 ZIP 成员，不解压、不执行包内任何程序。
- 逐条读取时检查所用字段的形状（正文、出处及嵌套结构）：类型不对报“成员#[位置]：字段 路径 应为…（原值…）”并整体回滚；缺字段、null 照旧按“未提供”处理，不跳过坏记录、不补默认值。

### 3.2 读取接口（只读，`routes/standards.py`，前缀 `/api/standards`）

| operation_id | 用途 |
| --- | --- |
| `listStandardDocuments` | 标准资料列表（含条目计数、覆盖范围） |
| `getStandardDocument` | 标准资料详情：来源包、成员、读取器版本、覆盖、问题 |
| `searchStandardEntries` | 按名称 / DE / CV 编号检索（F1 只做简单检索，不分页筛选） |
| `getStandardEntry` | 条目详情：类型化正文、出处、原记录、出 / 入引用；值域带代码行 |

### 3.3 页面（“标准与数据集”分组）

- 新增“标准资料”入口（列表 + 详情，work / document 外框）。
- “数据元”入口由规划中改为可用：检索框 + 结果；数据元详情显示定义、类型 S3、格式 N2、版本 V1.1、允许值原文，引用 CV02.01.101 显示为“本库收录的 WS/T 364.3—2023（原文未写年份，目录定位）”。
- 值域详情（从数据元跳入）：表名、所属标准与版本、13 个代码（字符串，01 不丢零）。“值域与代码”独立入口留到 F2。
- 每个条目有“出处”（包、成员路径、记录键、PDF 物理页 / 印刷页、原件可用性四态）与“原记录”（折叠的原始 JSON）。
- 无采用、发布、编辑按钮。

## 4 最小结构（迁移 0023）

- `source_package`：id、文件名、字节数、本地 SHA-256、预期 SHA-256、比对结论、来源 URL、Drive 文件 id、所属发布（`release_id`）、存放相对路径、成员清单 JSONB、登记时间。
- `source_document`：id、package_id、标准号（`WS/T 363.3`）、原文年份（`2023`，文本）、标题、资料族、读取成员及其 SHA（`members` JSONB）、原文版本标记、原 PDF 摘要与链接、读取器名与版本、源记录总数、已接入数（`covered_keys`）、导入时间。唯一：`(package_id, family, standard_no, standard_year, reader, reader_version)`，`NULLS NOT DISTINCT`。只有 `covered_keys`、`imported_at` 可更新（迁移 0024：`hdip_guard_update('covered_keys', 'imported_at')`）。
- `standard_entry`：id、document_id、`entry_type`（代码固定枚举）、源记录键、标识（DE / CV / 码值）、名称、父条目、顺序、`body` JSONB（按类型固定结构）、`raw` JSONB（原记录）、出处 JSONB（成员路径、JSON 位置、PDF 物理页、印刷页、表 / 行）、检索派生名。唯一：(document_id, entry_type, 源记录键)。
- `standard_reference`：id、from_entry_id、字段、引用原文、目标标准号、目标年份文字（可空）、目标标识、目标名称、引用性质（`value_domain` / `external_standard`）。**实施时调整**：解析结果（`explicit` / `catalog` / `unresolved` / `candidates`）不存库、读取时按目录计算，避免后来收录新版本时存下的目标过期或被静默改指；原文写明的年份不会被改指其他年份。

只追加：同一修订内条目不改；读取器修正结果不同 → 新的 `source_document` 修订。
