# 标准资料库：从原文封面补全发布 / 实施日期

日期：2026-11-04。起因：Peter 走查时发现很多标准没有发布日期和实施日期，但原文首页底部印着，例如 GB/T 2261.1—2003 封面左右两侧写着 2003-07-25 发布、2003-12-01 实施。不改表结构。

## 1. 范围与结果

- 对象：官网“卫生健康委员会”分类目录快照里没有这一条的 91 项标准，日期全空、状态都是待核实。其中 GB 5 项、GB/T 47 项、WS 34 项、WS/T 5 项。
- 结果：90 项补齐，共 179 个日期。没有补的有两项：
  - GB/T 2312—1980：封面只印“北京 1981”，没有发布、实施日期。
  - WS 377.4—2013：封面左下只印“2013-  -  发布”，月、日是空白；只补了实施日期 2014-05-01。
- 这两处随后由 Peter 在官网核实（2026-11-04），经人工更正表登记，不进封面日期表：
  - C0002 / C0003：GB/T 2312—1980 发布 1980-03-09、实施 1981-05-01（国家标准全文公开系统题录）；
  - C0004：WS 377.4—2013 发布 2013-12-27。

  依据地址只记了站点首页，没有记具体页面；至此 1260 项标准的发布、实施日期都已登记。
- 标准状态不变，仍为待核实。日期取自封面，不等于官方状态已核实。Peter 核实到这两项“现行”后，更正表扩展为也可登记状态（迁移 0028），经 C0005（GB/T 2312—1980）、C0006（WS 377.4—2013）登记为现行，核实日期 2026-11-04；其余 89 项仍为待核实。

## 2. 日期从哪里来

- **只取封面**。这批 PDF 的文字层大多是乱码（字体编码丢失），所以把每份原文的前 3 页渲染成图片，用 macOS Vision 做 OCR，取第一张读到“yyyy-mm-dd 发布 / 实施”的页；DOCX 直接读前 40 行文字。只读正文、合订、原格式文件，不读修改单。
- **转写成果只用来比对**。比对来源包括：
  - Drive 资料包（`/Volumes/新加卷/drive`）里带标准号的发布 / 实施日期字段；
  - MinerU 转写稿（`full.md`）的封面部分；
  - uniData 目录（`/Volumes/新加卷/mdm/uniData`）。

  比对结果写在“转写成果比对”列：一致 N 处 / 不一致 / 无转写。封面上没印的日期，不拿转写成果来补。
- 转写成果里混着通告日期、修改单日期、目录日期，所以有几处和封面不同：
  - WS 445.x 等标准的 2014-06-20：通告日期；
  - GB/T 4754—2017 的 2019-03-29：第 1 号修改单的实施日期；
  - GB/T 21715.6 / .8 的 2021-01-01、WS 446 的 2014-06-20：与封面不符。

  这些都以封面为准。
- **人看封面图片核对**（2026-11-04）：
  - 封面上的标准号没读出来，或者没有转写可比对：GB 12403、GB 3304、GB/T 17295、GB/T 2261.1、GB/T 35273、WS 376.3、WS 438；
  - 封面与转写不一致：GB/T 21715.6、GB/T 21715.8、WS 446；
  - OCR 漏读：WS 377.7 和 WS/T 452 的实施日期；
  - 封面本身没有：GB/T 2312、WS 377.4 的发布日期。

  核对结论写在生成脚本的 `REVIEWED`、`CHECKED` 里，并随结果写进“说明”列。
- WS 438—2013 的两份文件，文件名分别写着 WS/T 381、WS 439，但封面都是 WS 438—2013《裂头蚴病的诊断》，日期取自正文那一份。

## 3. 数据与登记

- 仓库数据表 `data/standards/cover-dates.csv`，一行一个日期。列：标准号、年份、字段（发布日期 / 实施日期）、日期、依据文件 sha256、依据页码、识别方式（封面 OCR / DOCX 封面文字 / 封面图片复核）、转写成果比对、说明。
- 生成：`api/scripts/cover_dates_build.py --transcripts <目录…>`。只能在 macOS 上运行（用 `cover_ocr.swift` 调 Vision，用 pdftoppm 渲染），只读资料、不碰数据库，重跑结果相同。
- 登记：`api/scripts/import_catalog.py` 把它叠加在生成目录与人工更正之后，**只填仍为空的日期**，官方目录和人工更正优先，不覆盖已有值。依据文件必须是这项标准已登记的文件。补上的日期追加一版目录，说明写“补：发布日期、实施日期（原文封面识别）”。
- 每份封面另记一条来源声明：来源“原文封面识别”，来源文件摘要 = 封面所在文件的摘要，记录位置 = 页码，原记录里是各日期的识别方式、比对结果和说明。和其他来源声明一样只追加：已登记的内容变了就整批拒绝。
- 表内不允许出现以下情况：标准不在目录里、字段不是发布 / 实施日期、日期为空、日期写法不对、依据文件不属于这项标准、页码为空、同一标准同一字段写了两行。测试见 `api/tests/test_std_cover_dates.py`。
